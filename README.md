# Italy News Bot

نسخه آزمایشی رایگان برای جمع‌آوری خبرهای مرتبط با ایتالیا و ارسال آن‌ها به کانال خصوصی بررسی.

## کار فعلی

- بررسی خبرهای تازه هر ۳۰ دقیقه
- دریافت خبرهای عمومی ایتالیا، مهاجرت و اطلاعیه‌های Protezione Civile
- حذف خبرهایی که قبلاً ارسال شده‌اند
- ارسال لینک خبر به کانال خصوصی
- عدم انتشار مستقیم در کانال عمومی
- عدم ترجمه خودکار در این مرحله

## Secrets required

- `TELEGRAM_BOT_TOKEN`
- `REVIEW_CHANNEL_ID`

## اجرای آزمایشی

در GitHub وارد بخش `Actions` شوید، سپس workflow با نام `Collect Italy News` را باز کنید و `Run workflow` را بزنید.
