# Italy News Bot V2

نسخه دوم ربات:

- ترجمه تیتر و خلاصه ایتالیایی به فارسی
- تلاش برای استخراج تصویر اصلی خبر
- ارسال عکس همراه کپشن فارسی
- درج نام منبع و لینک اصلی
- ارسال فقط به کانال خصوصی بررسی
- ادامه کار حتی اگر ترجمه یا عکس یک خبر شکست بخورد

## فایل‌هایی که باید جایگزین شوند

- `main.py`
- `requirements.txt`
- `.github/workflows/news.yml`

## اجرای تست

GitHub → Actions → Collect Italy News → Run workflow
